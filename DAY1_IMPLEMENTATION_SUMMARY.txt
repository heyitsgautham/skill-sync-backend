## 🔄 MATCHING WORKFLOW

1. STUDENT UPLOADS RESUME
   └─> Parse PDF/DOCX
       └─> Extract text & skills
           └─> Generate embedding (HuggingFace)
               └─> Store in ChromaDB

2. COMPANY POSTS INTERNSHIP
   └─> Parse description
       └─> Extract required skills
           └─> Generate embedding (HuggingFace)
               └─> Store in ChromaDB

3. AI MATCHING
   └─> Query ChromaDB with resume embedding
       └─> Find similar internships (cosine similarity)
           └─> Return top matches with scores
